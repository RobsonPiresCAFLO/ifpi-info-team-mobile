# IFPI Floriano Info Team — versão celular

Jogo arcade para apresentar o quadro de professores de Informática do IFPI Campus Floriano (Técnico e Graduação em TI).

Esta é a **versão 3**, que se adapta à tela vertical do celular: com o aparelho em pé, o jogo usa resolução 720×1280, com HUD, seleção, menus e botões de toque reorganizados. Na horizontal ou no computador, continua com o layout clássico em 1280×720. Girar o celular no meio da partida também funciona.

- **Jogar:** https://robsonpirescaflo.github.io/ifpi-info-team-mobile/
- **Tutorial de como foi feito:** https://robsonpirescaflo.github.io/ifpi-info-team-mobile/tutorial.html
- **Versão anterior (só horizontal):** https://github.com/RobsonPiresCAFLO/ifpi-info-team

**Sem a barra do navegador:** no celular, o jogo entra em tela cheia no primeiro toque. Para abrir sempre assim (inclusive no iPhone), use o menu do navegador → **Adicionar à Tela de Início**: o jogo vira um app com ícone próprio.

Dica: para ver o layout vertical no computador, abra o jogo com `?modo=retrato` no endereço.

Feito com HTML5 Canvas e JavaScript puro, sem bibliotecas.
